# Border-Sheild

BorderShield AI is an AI-powered border document screening prototype that helps officers verify passports and visas through upload-based screening, OCR/MRZ validation, simulated face verification, tampering analysis, metadata checks, risk scoring, watchlist and identity intelligence views, blockchain evidence tracking, officer decision support, and automated reports.

This prototype runs on a controlled local dataset of four sample documents (real/fake passport and real/fake visa) with deterministic demo results, delivered through a responsive dashboard with login/logout, light/dark themes, end-to-end screening workflows, forensic result views, reports, watchlist, analytics, and identity intelligence.
